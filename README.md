# Sistema Bancario Modular en Python

Sistema de gestión bancaria desarrollado en Python aplicando Programación Orientada a Objetos (POO), herencia, encapsulamiento y polimorfismo.

## Características
- Jerarquía de cuentas: Base, Caja de Ahorro y Cuenta Corriente con sobregiro.
- Gestión centralizada mediante la clase controladora `Banco`.
- Procesamiento de depósitos, retiros y transferencias seguras intercuentas.
- Cierre contable mensual automatizado y polimórfico.
